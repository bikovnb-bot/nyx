# История изменений

Версии Windows (`vX.Y.Z`) собираются и публикуются в GitHub Actions по тегу. Версии Android
(`android-vX.Y.Z`) собираются вручную скриптом `mobile/scripts/release-android.mjs`
(нужны подписывающий ключ и инструменты сборки, см. `mobile/README.md`).

## Windows 0.8.3

- **Расход трафика в заголовке подписки:** справа от названия «19,2 ГБ / 50 ГБ · 38 дн.» и тонкая
  полоска расхода (зелёная, с 70% жёлтая, с 90% красная). Без лимита полоски нет.
- **Kill switch:** снятие блокировки при выключении настройки и при старте с остаточным состоянием
  больше не блокирует окно; новое подключение дожидается возврата сети.
## Windows 0.8.2

- **Подключение не замораживает окно.** Раньше при каждом подключении окно на 1,6–1,9 с переставало
  отвечать: сетевой адаптер определял PowerShell. Теперь это занимает около 50 мс (маршруты читаются из
  `route print`, имя адаптера берётся у Node), а PowerShell остался запасным вариантом и работает
  асинхронно. Запуск туннеля стал асинхронным: можно отключиться или выбрать другой сервер, пока он готовится.
- **Быстрее старт.** Профили расшифровываются в фоне, пока приложение запускается, и меню трея с окном
  больше не ждут отдельный процесс PowerShell (~0,45 с).
- **Kill switch:** снятие блокировки идёт одним процессом PowerShell на все адаптеры, а кнопка
  «Отключить» не ждёт его окончания. Новое подключение дожидается возврата сети. При выходе из приложения
  сеть по-прежнему восстанавливается синхронно.
- **Страна сервера:** «.ru» в домене больше не делает сервер российским (профиль, названный по адресу
  `cloud.example.ru`, получает страну по IP).
- Из заголовка подписки убрано переименование: название подписки задаёт сервер.
## Android 0.2.4

- **Подписки группами**, как в Windows 0.8: «Избранное», «Мои серверы» и по группе на каждую подписку;
  группу можно свернуть, в свёрнутой видно подключённый сервер. Название подписки и расход трафика
  (полоска «19,2 / 50 ГБ · 38 дн.») берутся из ответа сервера; название подписки изменить нельзя.
- **Переименование сервера:** меню «⋮» → «Переименовать». Название, заданное вручную, не перетирается
  обновлением подписки.
- **Исправлено:** подписки в формате base64 (так их отдаёт 3X-UI) давали «в подписке нет ссылок
  vless»: общий код декодировал их через `Buffer` из Node, которого нет в WebView.
- Определение страны сервера по IP, если по названию страну определить нельзя, и 26 новых
  стран. «.ru» в домене больше не делает сервер российским.
- Имя сервера из профиля превращается в адрес до включения туннеля (раньше профили с доменом могли
  зависнуть); настройки туннеля на телефоне как в 0.2.1.

## Windows 0.8.1

- **Исправлено:** названия серверов из подписки не обновлялись у уже добавленных профилей: при
  обновлении менялась только ссылка, а название оставалось старым (например `England-1-…`, хотя сервер
  уже отдавал `🇬🇧 United Kingdom`). Теперь профиль, который вы не переименовывали, следует названию с
  сервера; название, заданное вручную, сохраняется. Исправление общее и войдёт в Android 0.2.4.

## Windows 0.8.0

- **Подписки как группы.** Список серверов разбит на группы: «Избранное», «Мои серверы» и по одной
  группе на каждую подписку. Группу можно свернуть и развернуть (состояние запоминается); в свёрнутой
  группе остаётся отметка подключённого сервера; поиск и фильтр по стране сами раскрывают нужные группы.
- **Одна кнопка «+» для серверов и подписок.** Вставленный текст определяется сам: `https://…` это
  подписка (с необязательным названием), `vless://…` это сервер; можно вставить несколько ссылок сразу.
- **Название подписки:** вводится при добавлении, берётся из заголовка `Profile-Title`, который
  присылает сервер, или из имени хоста; переименование из заголовка группы. Название, заданное
  вручную, не перетирается.
- В заголовке группы: обновить, переименовать, удалить подписку; расход трафика и срок из
  заголовка `Subscription-Userinfo` («10 ГБ из 50 ГБ · до 21.11.2026»).
- Меню в трее: избранное и свои серверы сверху, каждая подписка отдельным подменю.
- Вставка нескольких ссылок в однострочное поле больше не склеивает их.

## Windows 0.7.0

- **Второе ядро подключения — Xray.** Настройка «Ядро подключения»: «Авто» (по умолчанию),
  sing-box или Xray. «Авто» отдаёт Xray профили Reality и XHTTP, остальное — sing-box.
  sing-box по-прежнему ведёт туннель (TUN, маршруты, DNS, kill switch), а соединение с сервером
  несёт Xray через локальный SOCKS-порт, закрытый случайным паролем.
- Причина: серверы на Xray 26.9.8 и новее не принимают Reality-рукопожатие sing-box (любой версии
  1.11–1.14, а также 1.15.0-alpha.12): `reality verification failed`. Xray-клиент работает с серверами
  любых версий.
- Поддержка ссылок XHTTP (`type=xhttp`, старое имя `splithttp`); они идут только через Xray.
- `xray.exe` (версия закреплена в `release.yml`) скачивается в CI с проверкой SHA-256; оба ядра
  проходят проверку целостности. Без `xray.exe` Nyx продолжает работать на sing-box.
- Сборка релиза: информационный шаг проверки новой версии sing-box больше не может уронить сборку
  (запрос к API GitHub теперь с токеном и не фатален).

## Windows 0.6.2

- **Автообновление:** обрыв сети (смена VPN, DNS ещё не готов) больше не показывается как ошибка:
  проверка тихо повторяется до 3 раз; в журнал пишется одна короткая строка вместо ленты XML.
- **Страна по IP.** Если по названию профиля страну определить нельзя, один раз запрашивается
  геолокация IP сервера (отправляется только публичный IP) и запоминается. Название по-прежнему
  главнее.
- Ещё 26 стран распознаются по названию или городу (Румыния, Украина, Беларусь, Болгария, Чехия и др.).
