# Nyx

Минималистичный кроссплатформенный VPN-клиент для конфигураций
VLESS+WS+TLS (в том числе тех, что генерирует 3x-ui). Nyx не реализует
протокол самостоятельно — он генерирует конфиг для
[sing-box](https://sing-box.sagernet.org/) и запускает `sing-box` как
подпроцесс с TUN-интерфейсом, так что весь системный трафик идёт через
прокси.

Есть два способа использования: настольное приложение с иконкой в трее
(Windows) и CLI-утилита `vlessvpn` / `nyx` для Node.js.

## Скачать

Приложения выходят отдельными релизами с разными тегами: `vX.Y.Z` — Windows,
`android-vX.Y.Z` — Android. Ссылки ниже всегда ведут на последнюю версию каждого.

| | Windows | Android |
|---|---|---|
| **Последний релиз** | [Последний релиз Windows](https://github.com/bikovnb-bot/nyx/releases/latest) | [Последний релиз Android](https://github.com/bikovnb-bot/nyx/releases?q=android-v&expanded=true) |
| **Прямая ссылка на файл** | <!-- win-direct -->[Nyx-Installer.exe](https://github.com/bikovnb-bot/nyx/releases/latest/download/Nyx-Installer.exe)<!-- /win-direct --> | <!-- android-direct -->[Nyx-Android-0.2.2-arm64.apk](https://github.com/bikovnb-bot/nyx/releases/download/android-v0.2.2/Nyx-Android-0.2.2-arm64.apk)<!-- /android-direct --> |
| **Версия** | Windows 10/11, 64-бит | Android 7+, 64-битный процессор (arm64) |
| **Обновления** | сами, внутри приложения | сами, в «Настройки» → «О программе» |

**Windows.** `Nyx-Installer` — мастер установки в стиле приложения: сам скачивает
свежую версию Nyx, проверяет контрольную сумму и ставит её в папку пользователя без прав
администратора. Запасной вариант — обычный установщик `Nyx-Setup-x.x.x.exe`; именно его
использует автообновление внутри приложения.

**Android.** Скачайте APK и откройте его на телефоне: Android спросит разрешение на установку из
этого источника (его можно потом отозвать в настройках). Рядом с APK лежит файл `.sha256`
для проверки целостности. Приложение подписано ключом проекта, поэтому обновления ставятся
поверх без потери серверов.

### ⚠️ Предупреждение Windows SmartScreen при запуске

У Nyx пока нет платного code signing сертификата (это нормально для
маленьких open-source проектов — сертификат с проверкой личности/
организации стоит денег). Поэтому при первом запуске установщика
Windows SmartScreen покажет синий экран **«Windows защитила ваш
компьютер»**. Это не значит, что в файле есть вирус — просто Windows
ещё не видела достаточно загрузок этого конкретного exe, чтобы
доверять ему автоматически.

Чтобы продолжить:

1. Нажмите **«Дополнительно»** на синем экране
2. Нажмите **«Выполнить в любом случае»**

Если хотите убедиться в подлинности файла — сверьте его с исходным
кодом в этом репозитории или соберите установщик самостоятельно (см.
[«Сборка установщика»](#сборка-установщика) ниже).

## Возможности приложения

- Профили серверов с добавлением по `vless://`-ссылке, редактированием,
  копированием ссылки и импортом/экспортом в JSON
- Проверка доступности сервера (TCP-пинг) прямо из списка профилей
- График скорости передачи данных (↓/↑) и общий объём трафика за сессию
- Автозапуск при старте Windows
- Иконка и меню в системном трее, уведомления о состоянии подключения
- Вкладка «О программе» с версией приложения, версией sing-box и автором
- Автообновление: приложение само проверяет новые версии на GitHub,
  загружает их в фоне и предлагает установить одним кликом (кнопка
  «Проверить обновления» во вкладке «О программе»)
- Kill switch (вкладка «Настройки», по желанию): если сеанс sing-box
  неожиданно оборвётся, отключаются все сетевые адаптеры кроме
  VPN-туннеля, чтобы трафик не утёк в обход VPN
- Раздельное туннелирование (вкладка «Настройки», по желанию): список
  доменов и процессов Windows, которые идут напрямую в обход VPN
- Готовые правила маршрутизации (по желанию): сайты РФ (`.ru`, банки,
  госуслуги, маркетплейсы) идут напрямую, рекламные и трекерные домены
  блокируются. Списки (`vendor/rules/*.srs`, из SagerNet sing-geosite /
  sing-geoip) лежат в приложении и обновляются только вместе с релизом
- Выбор DNS-over-HTTPS (Cloudflare, Google, Quad9 или свой IP) и
  TLS fragment против блокировки по сигнатурам DPI (по желанию)
- Светлая и тёмная тема (или как в Windows)
- Понятные подсказки при проблемах с подключением: сервер не отвечает,
  ошибка TLS/Reality, занят порт, нужны права администратора и т. д.
- Проверка утечек: внешний IP, страна, сравнение с реальным IP и
  адресом сервера, сведения о DNS
- Ручное обновление списков сайтов РФ и рекламы (кнопка в настройках)
- Тест скорости через текущее подключение: задержка, разброс, загрузка и
  отдача (замер через Cloudflare, по кнопке, до 40 МБ данных)
- Полная резервная копия (профили + настройки) одним JSON-файлом
- Просмотр и копирование журнала диагностики прямо из интерфейса
- Проверка целостности бинарника sing-box: если он неожиданно изменится
  между запусками одной и той же версии Nyx, подключение блокируется
- Профили (адрес и UUID сервера) хранятся на диске зашифрованными через
  Windows DPAPI, привязанными к вашей учётной записи Windows — в отличие
  от предыдущей попытки через `safeStorage`, это переживает автообновления
- В журнале диагностики UUID сервера маскируется (виден только 4 первых
  символа) — полная ссылка профиля не попадает в файл логов
- При обычном запуске окно открывается сразу; при автозапуске вместе с
  Windows Nyx тихо стартует в трее. (Windows 11 может спрятать новый
  значок в «скрытые значки» — перетащите его на панель задач.)
- Автовыбор лучшего сервера (по желанию, в настройках): кнопка включения
  и пункт в трее подключают самый быстрый по пингу профиль
- Автопереподключение (по желанию): при обрыве Nyx повторяет подключение,
  затем переходит на запасной профиль или на самый быстрый из доступных.
  С включённым kill switch сеть блокируется только после неудачных попыток
- Подписки: ссылка на подписку (`https://…`) добавляет все её VLESS-серверы
  разом и обновляет список при запуске и раз в 6 часов. Сама ссылка хранится
  зашифрованной (DPAPI), в окно приложения она не передаётся
- QR-код профиля и импорт из QR (картинка или скриншот из буфера обмена)
- Статистика трафика по дням и по профилям за 7 и 30 дней; хранятся только
  счётчики байт, без адресов и сайтов
- Избранные профили, страна и флаг сервера в списке и в меню трея, запоминание
  размера и положения окна
- Запрос прав администратора (UAC) показывается только один раз — при
  первом запуске после установки/обновления. Дальше Nyx перезапускает
  себя с правами администратора через заранее зарегистрированную задачу
  Планировщика заданий Windows, без повторных запросов

## Требования (для запуска из исходников)

1. Node.js 18+
2. Бинарник `sing-box` в `PATH`, либо переменная окружения `SINGBOX_PATH`
   с полным путём к нему.
   Скачать: https://github.com/SagerNet/sing-box/releases
3. Права администратора/root (нужны для создания TUN-интерфейса).

## Установка из исходников

```bash
npm install
npm link   # делает доступными команды `vlessvpn` и `nyx` глобально
```

## Запуск GUI-приложения (Electron)

```bash
npm run gui
```

## Использование CLI

```bash
# Windows (от имени администратора) / Linux и macOS (через sudo)
vlessvpn connect "vless://<uuid>@5.145.176.51:443?type=ws&security=tls&path=%2F&encryption=none&fp=chrome#Test"
```

Ctrl+C отключает VPN и снимает TUN-интерфейс.

## Сборка установщика

```bash
npm run icons       # пересобрать все иконки из build/icon-source.jpg (Windows PowerShell)
npm run dist         # собрать NSIS-инсталлятор для Windows (release/)
npm run dist:portable  # собрать portable-версию (без самоповышения прав — см. примечание ниже)
npm run dist:installer # собрать мастер установки (installer/ → release-installer/)
```

## Выпуск релиза

Пуш git-тега `vX.Y.Z` в `main` запускает
[`.github/workflows/release.yml`](.github/workflows/release.yml):
устанавливает зависимости, прогоняет тесты, скачивает закреплённую
версию `sing-box`, собирает NSIS-инсталлятор (`npm run dist`) и
загружает его в [Releases](https://github.com/bikovnb-bot/nyx/releases)
вместе с метаданными для автообновления (`latest.yml`) через
`softprops/action-gh-release`. Загрузка вынесена в отдельный шаг,
а не через встроенный `--publish` electron-builder, потому что тот
пытается создать релиз параллельно из нескольких загрузок файлов и
иногда проигрывает эту гонку без единой ошибки в логе.

## Примечания

- Поддерживаются ссылки `vless://` с транспортами `tcp`, `ws` и `grpc`,
  а также с `security=none|tls|reality`.
- DNS по умолчанию резолвится через прокси (`remote-dns` в
  сгенерированном конфиге), чтобы избежать утечек.
- Portable-сборка Windows несовместима с самоповышением прав: обёртка
  electron-builder использует Job Object, который убивает уже
  запущенный элевированный процесс через несколько секунд после того,
  как исходный (неэлевированный) процесс завершается. Используйте
  обычный установщик (`npm run dist`) — это сборка по умолчанию.
